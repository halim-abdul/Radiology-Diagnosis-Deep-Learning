# Safety and governance

RESEARCH ONLY — NOT FOR DIAGNOSIS. Follow institutional ethics approval, data use agreements, access controls, and medical-device regulations when relevant. Never commit patient data, identifying metadata, private study identifiers, imaging archives, or trained weights containing potentially memorized PHI. The included key filter is a *logging guard*, not full de-identification; real DICOM de-identification must cover identifiers, private tags, embedded pixel text and linked records.
