# Research roadmap

**Implemented prototypes:** radiograph loading, grouped splits, DICOM pixel loader, NIfTI volume reader, CNN/ViT binary heads, 2D U-Net, tabular late fusion, image attribution, 3D affine geometry, binary metrics and research-only report draft formatting.

**Research directions (not implemented / not validated):** volumetric 3D transformers, multimodal VLM pretraining, external multicenter benchmarking, radiology report generation with evidence grounding, uncertainty and selective prediction, longitudinal registration, topology-aware segmentation, Laplace–Beltrami spectral priors, heat-kernel graph convolutions, persistent homology, Riemannian metric learning, equivariance, and image-to-world geometric consistency. Avoid presenting a roadmap item as completed.
