# DICOM pixel semantics

## Scientific motivation

MONOCHROME1 and MONOCHROME2 conventions can reverse apparent intensity.

## Mathematical or methodological point

Slope/intercept, rescale, windowing, inversion and modality LUTs are distinct transformations.
