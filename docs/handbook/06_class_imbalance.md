# Class imbalance

## Scientific motivation

Abnormality prevalence can be low; raw accuracy and ROC curves alone may obscure poor precision.

## Mathematical or methodological point

Positive predictive value changes with prevalence even when sensitivity and specificity remain fixed.

## Experimental design

Report PR-AUC, confusion matrices and clinically specified operating points. When designing a benchmark, document the source population, dataset provenance, validation design, key assumptions, and whether this hypothesis has actually been tested.

## Status and interpretation

This is a **research handbook note**, not a completed experiment, clinical result, or evidence of diagnostic validity. Revisit the relevant method, cite primary research sources in a formal manuscript, and keep patient data outside Git.
