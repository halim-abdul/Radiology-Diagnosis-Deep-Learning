# Lesion detection

## Research motivation

Bounding boxes encode localization, not merely study-level presence.

## Method and evaluation

Measure lesion-level sensitivity and false positive lesions per study under matching criteria. Separate the mathematical claim, implemented computation, and empirical evidence in any resulting paper. State voxel spacing, cohort selection, image modality, assumptions, split policy, and uncertainty where applicable.

## Reproducibility checklist

Record configuration, random seed, code version, input provenance, evaluation metric, ablations and known failure modes. Never mistake synthetic simulations for clinical benchmarks. **This file describes research methodology; it is not a validated clinical result.**
