# Spectral shape signatures

## Research motivation

Heat and wave kernel signatures measure multiscale geometric structure.

## Method and evaluation

Test resolution, boundary and noise robustness on anatomical meshes. Separate the mathematical claim, implemented computation, and empirical evidence in any resulting paper. State voxel spacing, cohort selection, image modality, assumptions, split policy, and uncertainty where applicable.

## Reproducibility checklist

Record configuration, random seed, code version, input provenance, evaluation metric, ablations and known failure modes. Never mistake synthetic simulations for clinical benchmarks. **This file describes research methodology; it is not a validated clinical result.**
