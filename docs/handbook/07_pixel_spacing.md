# Physical pixel spacing

## Scientific motivation

Clinical sizes are in millimeters, not raw pixel counts, and metadata can vary by study.

## Mathematical or methodological point

Area in physical units requires in-plane voxel spacing and correct orientation.

## Experimental design

Check metadata before computing lesion dimensions or converting masks into measurements. When designing a benchmark, document the source population, dataset provenance, validation design, key assumptions, and whether this hypothesis has actually been tested.

## Status and interpretation

This is a **research handbook note**, not a completed experiment, clinical result, or evidence of diagnostic validity. Revisit the relevant method, cite primary research sources in a formal manuscript, and keep patient data outside Git.
