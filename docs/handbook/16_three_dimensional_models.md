# 2-D versus 3-D models

## Scientific motivation

Volumetric networks can use inter-slice context but require more memory and careful anisotropy treatment.

## Mathematical or methodological point

A 2-D model cannot directly reason about complete volume continuity.

## Experimental design

Compare slice aggregation, 2.5-D stacks and true 3-D architectures. When designing a benchmark, document the source population, dataset provenance, validation design, key assumptions, and whether this hypothesis has actually been tested.

## Status and interpretation

This is a **research handbook note**, not a completed experiment, clinical result, or evidence of diagnostic validity. Revisit the relevant method, cite primary research sources in a formal manuscript, and keep patient data outside Git.
