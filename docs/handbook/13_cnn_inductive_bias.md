# CNN inductive bias

## Scientific motivation

Convolutions exploit locality and parameter sharing; pooling trades spatial precision for receptive field.

## Mathematical or methodological point

Receptive field growth need not imply anatomical understanding.

## Experimental design

Compare CNN encoders with strong non-deep baselines. When designing a benchmark, document the source population, dataset provenance, validation design, key assumptions, and whether this hypothesis has actually been tested.
