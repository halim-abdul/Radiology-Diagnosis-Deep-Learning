# Dataset governance

Candidate public research resources may include chest radiograph, brain tumor MRI, and segmented CT collections, subject to their *current* terms and approvals. Record usage rights, patient IDs, study acquisition, institution, scanner, orientation, labels, bounding boxes, segmentation provenance and data quality. Keep source media outside Git. Implement site-wise evaluation, duplicate screening and versioned manifests. Avoid embedding links to unverified mirrors.
