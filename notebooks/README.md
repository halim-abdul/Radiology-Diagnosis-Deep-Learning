# Research notebooks

Ten numbered notebooks cover synthetic radiology images, preprocessing, leakage control, CNNs, ViTs, U-Net geometry, voxel-world coordinates, input attribution, evaluation and safe report drafting. **Run the plotting cells to render example images**; no actual radiology scans are included. These are educational demonstrations, not validated results. Install the project with `pip install -e '.[test]'` before running them.
